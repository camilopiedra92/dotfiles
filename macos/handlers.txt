# The default app per file extension on every Mac: extension (no dot), then
# the app's bundle id. `#` starts a comment. macos/handlers.sh applies it from
# install.sh, for every role, and checks it from drift.sh, followed by the
# Mac's own macos/machines/<profile>/handlers.txt; an extension is in one or
# the other, never both.
#
# Only extensions whose handler differs from Apple's own choice, the same
# rule as defaults.txt. A bundle id is what `duti -x <ext>` prints on its
# third line, or `osascript -e 'id of app "Name"'`.
